# Task Set 9

### Task 1
Write a program to find the root of the function $f(x) = e^x - 3x$ using the bisection method.
The user enters the interval $[a, b]$ via the console.
The precision $\epsilon$ should be set to $10^{-6}$.

---

### Task 2
Write a program to find the root of one of the following functions using the bisection method:
1. $f(x) = e^x - 3x$
2. $f(x) = \cos(x) - x$
3. $f(x) = -2x + 0.25 + \sin(x)$
4. $f(x) = \log_{10}(x) + x^3$

The user chooses the function and enters the interval $[a, b]$ via the console.
The precision $\epsilon$ should be set to $10^{-6}$.
