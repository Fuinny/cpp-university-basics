# Task Set #3

---

### Task 1
Write a C++ program that determines whether a triangle can be formed from the given segments.

Initial data: lengths of three segments `a`, `b`, `c`. Data is entered using the keyboard.

---

### Task 2
Write a program to solve the quadratic equation:

```math
ax^2 + bx + c = 0
```

Initial data: equation coefficients `a`, `b`, `c`. Data is entered using the keyboard.

---

### Task 3
Write a program to calculate BMI coefficient and display the results to the console.

Initial data: height and weight. Data is enterted using the keyboard.
