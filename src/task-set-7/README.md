# Task Set 7

### Task 1
Implement the **Bubble Sort** algorithm.
The program sorts a predefined array of integers and displays the state of the array after each pass.

---

### Task 2
Implement the **Insertion Sort** algorithm.
The program sorts a predefined array of integers and displays the state of the array after each pass.

---

### Task 3
Implement the **Selection Sort** algorithm.
The program sorts a predefined array of integers and displays the state of the array after each pass.

---

### Task 4
Implement the **Rank Sort** algorithm.
The program calculates the rank of each element (its final position in the sorted array), stores these ranks in an auxiliary array, and then uses them to produce the sorted array.

---

### Task 5
Implement the **Shaker Sort** algorithm.
This is a variation of Bubble Sort that sorts in both directions (left-to-right and right-to-left) during each iteration.
The program displays the state of the array after each directional pass.

---

### Task 6
Implement the **Binary Insertion Sort** algorithm.
This is a variation of Insertion Sort that uses binary search to find the correct position to insert the current element, reducing the number of comparisons.
The program displays the state of the array after each insertion pass.
