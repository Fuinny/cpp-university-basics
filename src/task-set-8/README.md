# Task Set 8

### Task 1
Write a program to transpose a matrix.
The matrix dimensions and elements are read from a file named `matrix.txt`.
The result should be saved to a file named `result.txt`.

---

### Task 2
Write a program to find the largest element in a matrix and its coordinates.
The matrix dimensions and elements are read from a file named `matrix.txt`.
The result should be displayed in the console.

---

### Task 3
Write a program to calculate the sum of two matrices.
The matrix dimensions and elements for both matrices are read from a file named `matrix.txt`.
The result should be saved to a file named `result.txt`.

---

### Task 4
Write a program to calculate the element-wise product of two matrices.
The matrix dimensions and elements for both matrices are read from a file named `matrix.txt`.
The result should be saved to a file named `result.txt`.
